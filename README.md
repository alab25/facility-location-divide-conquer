# Facility Location: Divide and Conquer

This repository contains a Python implementation designed to solve the Facility Location problem utilizing a divide-and-conquer algorithmic approach[cite: 2]. 

## 📂 Repository Structure

*   **`divideconquer.py`**: The primary Python script containing the core logic for the divide-and-conquer algorithm[cite: 2].
*   **`README.md`**: Project documentation[cite: 2].

## 🚀 Overview

The Facility Location problem is a classic optimization and operations research challenge. It involves determining the optimal placement of facilities (like warehouses or servers) to serve a set of demand points (like customers or client nodes) in order to minimize total costs, such as distance, setup, and transportation. 

This specific implementation tackles the problem using the **Divide and Conquer** paradigm[cite: 2]. By recursively breaking the spatial data or node sets down into smaller, more manageable sub-problems (divide) and combining their localized optimal results (conquer), the algorithm efficiently computes the best facility locations.

## 💻 Usage

Ensure you have Python 3.x installed. To run the algorithm, navigate to the project directory and execute the script from your terminal:

```bash
python divideconquer.py
```
